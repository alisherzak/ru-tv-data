# ru-tv-data

Данные для приложения «Русское ТВ» (Android): список каналов, телепрограмма, логотипы и релизы APK.

Каналы — из открытого каталога [iptv-org](https://github.com/iptv-org/iptv) (Unlicense), телепрограмма — iptvx.one. Потоки принадлежат вещателям; здесь только ссылки. Без гарантий: каналы приходят и уходят.
